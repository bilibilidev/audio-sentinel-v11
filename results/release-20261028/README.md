## Linux结果

清理后的源码在Ubuntu x86_64/GCC 11.4重新构建，十组消融共60个模型完成C运行。正式配方五折仍为337/390，外部65条完整录音分类为57/65（87.69%）。PCM/WAV核对覆盖70条，ASan/UBSan覆盖65条外部录音。

同一Linux C前端特征上的NumPy核对共7,800个模型/录音组合，类别一致，最大概率差约2.39e-7。文件读取分块1、997、4096样本的结果一致。完整合成关键词回归为9正例、2负例，HTTP/MQTT本机回环及五个Linux演示均通过。

本次属于当前源码的主机C复测，没有重新训练模型、构建新固件或连接开发板。外部65条仍为开发集，原基线、时延和真板数据保留各自实验日期。

`summary.json`记录结果，`source-hashes.json`记录本次活动源码与配置的SHA256。详细实验方法见[训练说明](../../training/mlp_study/README.md)，视频操作见[demos](../../demos/README.md)。
