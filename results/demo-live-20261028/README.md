# Linux C 实时演示

五项演示在Ubuntu内现场执行，实验记录统一放到命令输出末尾。输入复用本地已确认的录音和合成关键词，模型、特征及门限保持正式配置。

本次五条录音在干净、20/10/5 dB输入下分别分类正确5/5、4/5、4/5、3/5。加噪WAV现场生成，并按完整录音调用C分类。关键词为9条合成正例和静音、低噪声2条负例，匹配结果分别为9/9和2/2。背景未发送网络事件，咳嗽通过HTTP和MQTT送达相同JSON。

模型入口编译C测速程序，从实际数组读取9,413个参数、9,413 B INT8权重/偏置及912 B归一化/scale。三秒输入先预热3次，再处理20次；本次计时原始值、RSS、VmHWM和ELF大小保存在`summary.json`中。时间为Linux WAV处理，内存来自当前C程序的`/proc/self/status`。

这些数值描述本次小规模演示。390条官方五折和65条外部开发集仍使用各自实验记录，显示在实时操作之后。`source-hashes.json`给出本轮demos源码哈希，运行说明见[demos](../../demos/README.md)。
