## 审计结论

- 390条原始文件哈希、官方标签映射、356个源ID的折归属核验通过；同源不同take和所有窗口不跨保留折。未发现标签映射错误或跨折泄漏。
- 归一化仅拟合各训练折；增强背景取同一官方折，7,800个混合来源均核查，不引入保留折背景。
- ESC是整段弱标签。1950个一秒片段中，低于旧门限的咳嗽93/200、玻璃119/200、婴儿4/200；低能量不代表源标签错。强制给每秒贴整段标签会增加窗口标签噪声。
- MLP训练录音分类约98%–99%，保留折约79%–83%；CNN训练约88%–90%、保留折约75%–86%，参数和归一化均有限。存在泛化差距和正则/容量取舍，未发现训练数值崩溃；不能仅凭外部更高断定ESC训练出错。
- 旧App聚合与离线口径不一致是明确问题。同次MLP：离线完整均值318/390；旧前三秒规则298/390；扩展五秒但保留事件最大值289/390。新默认采用训练一致的窗口概率均值，不做低能量改判和最大事件覆盖。
- C/Python MLP前端存在浮点差异。折1外部567窗口最大原始特征差0.07014，概率差0.000425；改用同一C特征时网络概率差约2.39e-7，65条预测未变化。该差异有单独诊断，未伪称所有端严格1e-4一致。

## 执行边界

本轮为实际Windows原生C（现有MinGW GCC6.3.0）；训练使用现有Python3.12.14/NumPy2.3.5/CPU PyTorch2.14.1。Ubuntu连接中断，未声称本轮Linux、完整OpenVela模拟器或真实开发板重测。旧CNN真板时延不能转用到新MLP。
UI仍按三秒arecord文件采集，不是无间断PCM流；CNN每100ms流式CLI保留。关键词仍为合成模板CLI原型；网络仅可选--report，不自动从UI或关键词触发。

训练入口：training/retrain_mlp_audit.py和training/cnn_v2/train_from_scratch.py（新增--seed-base，默认种子不变）。C审计入口scripts/evaluate_retraining_audit.py。逐文件结果、每类指标及各折/全量权重均保留。
新默认App集成结果另见app-verification.json；仅主机测试，未更新/烧录板镜像。
