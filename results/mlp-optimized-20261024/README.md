## 五折协议与数据预算

每个外层官方折保留，仅在其余折内选择配置/epoch（下一折验证、另外三折训练），选型分数为0.6准确率+0.3宏召回+0.1婴儿召回。归一化和asinh尺度仅拟合训练集；同源录音/秒窗不跨保留折。五个外层模型和最终全量模型均重新随机初始化。

正式流程候选空间为原390条的8种MLP配置，以及扩充背景的3种配置；合并时只比较内层分数，不按外层正确数挑折模型。各折配置及训练预算不同：折1为原数据128隐藏层；折2–4为扩充背景128隐藏层；折5为原数据96隐藏层。**333/390是这一选择流程的结果，不是固定最终92→96→5配方的五折成绩。**

扩充空间使用1992条ESC音频（原390评测集合不变、另1602背景）；排除8条额外音频，以避免完整ESC元数据中4个跨折源ID造成泄漏。保留折的所有背景也排除。全量正式模型由平均内层分数选定`window96_asinh`，仅训练原390条，60轮。

反复开发比较和部署选择已参考旧/本轮结果；外部65条更早已参与项目开发。即使每次训练不读外部文件，也不能把这里当成全新独立盲测或无偏架构排名。
