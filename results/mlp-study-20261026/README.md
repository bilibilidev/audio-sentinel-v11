# Tiny MLP：重新训练、消融与实际 Linux C 验证（2026-10-26）

正式权重仍为`2c74151c…61610f9e9`，92→96→5、9,413参数，本轮未替换模型或调整0.80门限。60个消融模型从零训练；正式配方的全量模型参数、归一化和asinh尺度与正式模型逐项一致。原始音频和私人环境不公开。

## 基线和消融

以下MLP为**固定正式配方**：每折只训练其余4个官方折，固定60epochs、AdamW/lr0.002、weight decay0.001、label smoothing0.02、dropout0.15；余弦调度周期仍为240epochs，与正式训练相同。每条录音5个一秒窗口，所有窗口、增强来源和归一化均限制于训练折；同源ID不跨保留折。所有变体使用相同种子/次序，仅改表中单个因素。

新固定配方337/390与历史内层选型333/390是**不同实验口径**；后者含不同宽度和扩充背景，不能混写。本轮另外重新编译旧六个选型模型，Linux仍为333/390、57/65。新固定配方各折为72/84、75/84、66/72、58/72、66/78，合计337/390；Float参考和INT8存储/浮点C均为337/390。

SVM/RF/PANNs均重新拟合、重新评分，使用同一390份ESC和65份外部PCM16 WAV字节。MFCC基线为全录音52维统计；MLP为逐秒92维特征后概率均值，输入统计口径有区别。SVM/RF/PANNs超参数仅按内层`0.6准确率+0.3宏召回+0.1婴儿召回`选择，再训练外层四折；最终参数取平均内层效用。PANNs使用额外AudioSet预训练，冻结512维特征+线性SVM，并非等数据预算或端侧部署模型。

训练及基线Python运行于既有Windows CPU环境；下列MLP消融/正式模型均在**实际Ubuntu22.04 x86_64/GCC11.4**重新编译C运行。未在Ubuntu安装PyTorch或NumPy；数值对照使用新导出的Linux C特征与Windows NumPy，不能称为Linux Python训练。

## 噪声和告警门限

|固定full保留折|正确/390|准确率|宏召回|
|---|---:|---:|---:|
|干净|337|86.41%|84.24%|
|20 dB高斯噪声|302|77.44%|72.11%|
|10 dB高斯噪声|282|72.31%|58.39%|
|5 dB高斯噪声|267|68.46%|48.41%|

噪声由每条干净PCM的均方根独立缩放、固定种子生成，最终量化/裁剪；`noise-inputs.json`记录目标/实际SNR和输入哈希。仅改变保留折输入，不重训或挑模型；高斯扰动不等于真实房间噪声。新版在强噪声下明显下降，不能复用原v11的噪声鲁棒性结论。

外部argmax每类召回为背景12/13、咳嗽10/12、玻璃7/9、婴儿17/20、狗叫11/11。one-vs-rest FPR分别为7.69%、3.77%、3.57%、0%、0%，完整分母见`per-class-and-threshold.json`，不是每小时误报。

**按全片概率套用CLI的非背景且置信度>0.80规则**，正确触发为咳嗽1/12、玻璃1/9、婴儿4/20、狗叫1/11。不能把85%婴儿分类召回写成85%告警召回；也不能把这些全片结果当成三秒UI或麦克风现场告警率。本轮没有为提高分数改变门限。

## 轻量化与边界

|网络指标，5秒输入|Tiny MLP|PANNs Cnn6|
|---|---:|---:|
|可学习网络参数|9,413|4,837,455|
|网络Conv/Linear MAC|46,560|4,953,927,168|

MLP参数约为1/514、网络MAC约为1/106,399。PANNs另有2,565个线性SVM系数、固定前端及23,698,321B checkpoint；上述MAC排除双方前端、非线性等，不能直接当作总耗时或能耗比。PANNs精度更高；MLP的选择依据是端侧轻量化。**没有功率计，功耗/能耗未测；PANNs未做同板部署。**

本轮不是完整OpenVela/goldfish或真实开发板测试，未编译/烧录新镜像，未验收麦克风、UI连续采集、1h/24h稳定性或每小时误报。UI仍为三秒arecord文件；已有板端/CNN历史数据仅作历史证据，不能替代本轮MLP板端验收。
